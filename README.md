## MSc Data Analytics – Coursework Project

This repository contains coursework completed as part of the **MSc Data Analytics** programme for the module  
**Predictive Analytics and Machine Learning using Python**.

The project demonstrates the practical application of machine learning techniques for classification, clustering, and regression using Python.

---

## Project Objectives
- Apply decision tree concepts using entropy and information gain
- Perform unsupervised data segmentation using K-Means clustering
- Model and analyse non-linear relationships using regression techniques
- Demonstrate end-to-end machine learning workflow and evaluation
